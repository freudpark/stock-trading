# 📈 AI 주식 자동 매매 프로젝트 (Stock Bot)

본 프로젝트는 모바일(Termux) 환경과 클라우드(AWS EC2) 환경을 하이브리드로 연동하여, 다중 AI(Multi-AI)를 통해 주식 시장을 분석하고 자동 매매를 수행하는 관제 시스템입니다.

## 🏗️ 전체 시스템 아키텍처 (Hybrid AI Validation)

본 시스템은 기기의 자원 한계를 극복하고 코드 검증의 신뢰성을 높이기 위해 3개의 주요 계층(Layer)으로 나뉘어 작동합니다.

### 1. 개발 및 실행 계층: 모바일 환경 (Termux)
- **역할:** 주식 봇의 메인 서버(Flask 대시보드) 실행 및 데이터 수집.
- **특징:** 모바일 환경의 특성상 무거운 AI 모델을 직접 돌리지 않고 1차적인 로직 처리와 UI 제공에 집중합니다.

### 2. 코드 및 상태 동기화 계층: GitHub & 브릿지 스크립트
- **`agy_bridge.py`**: Termux와 원격 AWS 서버를 이어주는 통신 브릿지 프로그램입니다.
- **자동 동기화 (`--sync`)**: 대용량 코드베이스를 메신저로 전송하는 한계를 극복하기 위해, 브릿지 스크립트 실행 시 자동으로 GitHub 저장소에 코드를 `push`하고 AWS 서버에 텔레그램 API를 통해 `pull` 지시를 내립니다.

### 3. 정밀 검증 계층: 원격 클라우드 (AWS EC2 + Claude Code)
- **역할:** Termux에서 전송된 텔레그램 명령을 수신(리스너)하고, GitHub에서 최신 코드를 내려받은 뒤 **Claude Code**가 코드를 정밀하게 분석·검증(Cross-Check)합니다.
- **결과 보고:** 검증이 끝나면 그 결과를 다시 텔레그램을 통해 Termux 환경으로 회신합니다.

## 🚀 파이프라인 진행 방식

매매 결정은 다음 3단계 AI 파이프라인을 거쳐 진행됩니다:

1. **1단계 (MBD Free AI):** 실시간 뉴스 및 시세 데이터 수집, 기초적인 차트(이평선, 골든크로스 등) 1차 필터링.
2. **2단계 (Codex Engine):** 1차 필터링된 종목에 대해 퀀트(Quant) 변동성 돌파 전략 및 리스크 모델링을 적용하여 정밀 검증.
3. **3단계 (Claude Code):** GitHub 원격 연동을 통해 시스템의 최종 로직 및 매수 시그널에 대한 교차 검증(Cross-Check)을 수행 후, 사용자에게 최종 승인을 요청.

## 📊 모니터링 (대시보드)

`dashboard/app.py`를 통해 제공되는 웹 대시보드에서는 다음 항목들을 실시간으로 모니터링할 수 있습니다:
- 현재 계좌의 평가 자산 및 당일 수익률
- 3단계 AI 파이프라인의 진행 상태
- **📡 AWS 원격 코드 검증 (GitHub 연동)**: 최근 코드 동기화 시간 및 원격 Claude 검증 상태 모니터링
- 매매 실행에 대한 수동 승인(✅) 및 반려(❌) 제어 기능
